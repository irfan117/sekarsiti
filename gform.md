## 📐 BAGIAN C — Panduan Upload Foto

### Format yang Didukung
- **JPG / JPEG** ✅ (direkomendasikan)
- **PNG** ✅ (gunakan untuk logo/emblem transparan)
- **WEBP** ✅
- **HEIC** ❌ (tidak didukung, minta konversi ke JPG dulu)

### Resolusi Minimal
| Jenis Foto | Resolusi Minimal |
|---|---|
| Foto Sampul / Hero | 800 × 1000 px |
| Foto Potret Mempelai | 600 × 800 px |
| Foto Galeri | 600 × 600 px |
| Foto Filmstrip (Reel Sinematik) | 900 × 600 px (landscape wajib) |
| QRIS / Emblem | 500 × 500 px |

### Cara Upload via Google Form
1. Gunakan pertanyaan bertipe **"Upload File"** di Google Form
2. Batasi tipe file ke: `jpg, jpeg, png, webp`
3. Batasi ukuran maksimal: **10 MB per file**
4. Untuk galeri, gunakan tipe **"Upload File"** dengan **"Izinkan beberapa file"**

### Cara Upload via Google Drive
Jika mempelai ingin kirim via Google Drive:
1. Minta mereka upload ke Google Drive
2. Klik kanan file → **"Bagikan"** → atur ke **"Siapa saja yang memiliki link dapat melihat"**
3. Salin link-nya dan tempel di kolom GForm
4. Admin bisa paste link Drive langsung ke field di dashboard — sistem akan otomatis konversi ke thumbnail

## 🤖 BAGIAN D — Cara Pakai Fitur "Setup Cepat via AI"

Setelah Google Form terisi, admin bisa mempercepat proses pengisian data undangan dengan fitur AI di dashboard.

### Langkah-langkah:

1. **Buka Google Sheets** dari respons Google Form
2. Pilih **1 baris respons** mempelai yang ingin diproses
3. **Salin seluruh isi baris** (Ctrl+A → Ctrl+C di baris tersebut), atau salin kolom Pertanyaan + Jawaban
4. **Buka Dashboard Admin** → Klik order mempelai → Tab **"Setup Cepat AI"**
5. **Tempel teks** di kolom input yang tersedia
6. Klik tombol **"Proses dengan AI"**
7. Review hasil — AI akan otomatis mengisi semua field yang terdeteksi
8. Klik **"Tata Ulang Aset Cerdas (AI)"** untuk mendistribusikan foto ke slot yang tepat
9. Periksa dan simpan

### Format yang Dikenali AI

AI parser bisa mengenali tiga format teks:

**Format 1 — Google Sheets Copy-Paste (TSV):**
```
Nama Panggilan Wanita	Sekar
Nama Panggilan Pria	Adhitya
Tanggal Pernikahan	Sabtu, 12 April 2025
```

**Format 2 — Google Form Response Summary:**
```
Nama Panggilan Wanita
Sekar

Nama Panggilan Pria
Adhitya
```

**Format 3 — Ringkasan WhatsApp / Teks Bebas:**
```
Bride: Sekar Arum Sari
Groom: Adhitya Wicaksono
Tanggal: 12 April 2025, Akad 08.00 WIB, Resepsi 11.00 WIB
Gedung: Graha Budaya Surakarta
```

## 📌 Tips Operasional Admin

1. **Buat 1 Google Form master** dengan semua pertanyaan, gunakan fitur **"Section based on answer"** untuk menampilkan Seksi 8 sesuai template.

2. **Cek foto filmstrip** sebelum proses — pastikan semua foto landscape (lebar > tinggi). Jika ada portrait, minta mempelai kirim ulang.

3. **Foto dengan wajah terpotong** di galeri akan mempengaruhi kualitas undangan. Ingatkan mempelai untuk upload foto full-body atau minimal setengah badan.

4. **Link Google Drive harus publik** — minta mempelai ubah sharing ke "Siapa saja yang memiliki link".

5. **Nama file foto tidak perlu diubah** — AI placement akan otomatis menentukan slot terbaik berdasarkan analisis konten.

6. **Simpan respons GForm sebagai Google Sheets** — ini memudahkan copy-paste ke fitur AI Setup di dashboard.
